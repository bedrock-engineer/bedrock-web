## Fetch a CPT from the BRO

[brodata](https://pypi.org/project/brodata/) fetches a sounding from
the public [BRO](https://basisregistratieondergrond.nl/) API and parses
the XML.

```python marimo editor=true
import marimo as mo
import pandas as pd

from brodata.cpt import ConePenetrationTest
from cpt_anywidget import CPTViewer
```

```python marimo editor=true
cpt = ConePenetrationTest.from_bro_id("CPT000000061388")
```

Edit the id above to fetch another public CPT. The whole page reruns
with the new sounding.

## Tidy the data

Pick the channels, coerce the numeric strings, and compute the vertical
coordinate in m NAP from the surface offset:

```python marimo editor=true
df = cpt.conePenetrationTest.dropna(axis=1, how="all").sort_index()

cpt_data = df.reindex(
    columns=["depth", "coneResistance", "localFriction", "frictionRatio"]
).apply(pd.to_numeric, errors="coerce")

cpt_data["nap"] = float(cpt.offset) - cpt_data["depth"]
```

The DataFrame follows the
[data contract](/docs/cpt-anywidget/reference/intake/): tidy columns of
equal length, one row per depth sample. The constructor handles the
rest: NaN to `None`, rows sorted to render order.

## Pick the channels

The multiselect is a marimo UI element. The viewer cell reads its
value, so the chart rebuilds when you change the selection.

```python marimo editor=true
channel_select = mo.ui.multiselect(
    options=["coneResistance", "localFriction", "frictionRatio"],
    value=["coneResistance", "localFriction", "frictionRatio"],
    label="Channels",
)
channel_select
```

## Show the viewer

```python marimo editor=true
CPTViewer(
    cpt_data,
    vertical="nap",
    channels=list(channel_select.value),
    annotations=[
        {
            "at": float(cpt.offset) - 1.2,
            "label": "GWL",
            "color": "steelblue",
            "dash": "4 2",
        },
    ],
)
```
