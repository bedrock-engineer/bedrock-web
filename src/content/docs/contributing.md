Contributing isn’t just about writing code:

* Use `bedrock-ge` and provide feedback
* Share how you use Bedrock
* If you have a project with publicly available GI data, please share that in [a discussion](https://github.com/orgs/bedrock-engineer/discussions), such that we can create a tutorial from it.
* Help each other out, e.g. by replying to questions in the discussions or [bedrock-ge issues](https://github.com/bedrock-engineer/bedrock-ge/issues)
* Spread the word about Bedrock!
* Writing and improving documentation and tutorials
* Most pages on the this website can be edited, so if you see a spelling mistake or have a suggestion on how to explain something better, please fix it by clicking the "Edit page" button in the bottom left of the page.
